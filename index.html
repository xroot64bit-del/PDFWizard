Fitur

Semua yang Anda butuhkan untuk bekerja dengan PDF

Dari merapikan urutan halaman sampai mengedit isinya, tanpa berpindah-pindah aplikasi.

▦

Susun halaman secara visual

Lihat setiap halaman sebagai thumbnail. Seret untuk mengubah urutan, pilih halaman ganjil/genap, balik urutan, tukar ganjil-genap, lengkap dengan Undo/Redo.

⇄

Gabung & pecah

Gabungkan beberapa PDF dan gambar (PNG, JPEG, BMP). Ekstrak halaman terpilih menjadi satu PDF, atau pecah menjadi satu file per halaman.

✎

Edit teks dan gambar di dalam PDF

Ubah isi, font, ukuran, dan warna teks; tambah, hapus, atau pindahkan. Pindah, ubah ukuran, putar, atau ganti gambar. Dilengkapi zoom agar presisi.

W

Ekspor ke DOCX

Setiap halaman menjadi satu halaman Word dengan tata letak yang dijaga. Teks tetap bisa dipilih dan diedit di Word.

</>

Ekspor ke HTML & Markdown

Tombol “To Data” membuat folder per halaman berisi index.html, index.md, dan folder gambar hasil ekstraksi.

⟲

Rotasi, crop, skala, booklet

Putar, potong, dan skalakan halaman terpilih. Tambahkan overlay/underlay, buat booklet cetak lipat, dan atur metadata dokumen.

Cara kerja

Tiga langkah, selesai

Buka & susun

Seret file PDF atau gambar ke jendela, lalu rapikan halaman dengan drag & drop, rotasi, crop, atau hapus.

Edit halaman

Pilih satu halaman dan buka Edit Page untuk mengubah teks dan gambar langsung di dalam halaman.

Simpan atau ekspor

Simpan sebagai PDF baru, atau ekspor ke DOCX, HTML, dan Markdown sesuai kebutuhan.

Ekspor data

Dari PDF ke format yang bisa Anda olah

Pilih halaman yang ingin diambil, lalu klik To Data. Hasilnya tertata rapi per halaman.

  • HTML dengan posisi teks dan gambar yang mengikuti PDF asli.
  • Markdown berisi judul, paragraf, daftar, dan referensi gambar.
  • Gambar yang ada di halaman diekstrak sebagai resource.
  • DOCX satu section per halaman dengan ukuran halaman yang sama.

Aktivasi

Aktivasi sederhana, per komputer

Fitur menerapkan hasil Edit Page dan Export DOCX memerlukan activation key yang unik untuk komputer Anda.

Salin Hardware ID

Saat aplikasi meminta aktivasi, salin Hardware ID komputer Anda atau kirim langsung lewat tombol email di dialog.

Terima activation key

Pengembang membuat activation key berdasarkan Hardware ID tersebut dan mengirimkannya kepada Anda.

Masukkan & selesai

Tempel key atau muat file serial.key. Key tersimpan, jadi Anda tidak perlu mengisinya lagi.

FAQ

Pertanyaan yang sering diajukan

Sistem operasi apa yang didukung?

PDF Wizard adalah aplikasi desktop untuk Windows, tersedia sebagai versi 32-bit dan 64-bit.

Apakah file saya diunggah ke internet?

Tidak. Seluruh pemrosesan terjadi di komputer Anda, dan verifikasi activation key juga dilakukan secara lokal.

Format apa yang bisa dibuka?

File PDF (yang tidak diproteksi password) serta gambar PNG, JPEG, dan BMP, yang otomatis menjadi halaman PDF.

Apakah teks dari PDF hasil scan bisa diedit?

Tidak. PDF hasil scan berisi gambar, bukan teks, sehingga yang bisa diedit hanyalah gambarnya.

Seberapa mirip hasil DOCX dengan PDF-nya?

Tata letak dijaga: posisi, ukuran, dan warna teks serta gambar mengikuti PDF. Karena Word memakai font sendiri, lebar teks bisa sedikit berbeda, dan tabel menjadi teks berposisi, bukan tabel Word.

Siap merapikan PDF Anda?

Unduh PDF Wizard dan mulai menyusun, mengedit, serta mengonversi dokumen Anda hari ini.
